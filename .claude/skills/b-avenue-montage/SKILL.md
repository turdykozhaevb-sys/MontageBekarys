# B-Avenue Montage

Стиль снят с 5 референсов (BI Group: Arena Vista, 30/70 + Отбасы банк, 600 квартир, #SummerWithBIgroup, Korkem Ипотека).
Полный разбор с замерами, палитрами, размерами и таймингами: [reference.md](reference.md). **Прочитай его перед монтажом.**

## Состав скилла

| Файл | Что делает |
|------|-----------|
| `reference.md` | Полный стайл-гайд: структура, ритм, шрифты, субтитры, цвет, графика, аутро, звук, чек-лист |
| `scripts/grade.sh <warm\|clean\|pop> in out` | Кроп в 1080×1920 + цветокор пресетом |
| `scripts/mix.sh voice music out.wav [gain]` | Голос (шумодав, EQ, компрессия) + музыка с ducking → loudnorm −14 LUFS / −1 dBTP |
| `scripts/export.sh video out [subs.ass] [audio.wav]` | Прожиг ASS-субтитров со шрифтами из `fonts/`, H.264 1080×1920, AAC 192k, faststart |
| `scripts/fonts.sh` | Докачать шрифты в `fonts/` (если папки нет) |
| `templates/subs.ass` | Стили: `Glow`+`Head` (заголовок со свечением), `Accent` (жёлтый), `Big` (гигантская цифра), `Neon` (Unbounded, неон), `Sub` (нижний перевод) |
| `templates/motion-overlay.html`, `templates/motion-overlay-factors.html` + `scripts/render_overlay.js` | Моушн-оверлей на HTML+JS (Playwright → прозрачные кадры → ffmpeg). `motion-overlay.html` — 8-секундный хук (график цены, «5», кружки 1–5). `motion-overlay-factors.html` — длинный ролик 84 c: хук, 5 факторов (заголовок + карточка-инфографика на каждый, трекер 1–5 сверху), бренд-титры, финальный чек-лист; библиотека иконок `IC`, билдеры `ttl/card/item/chip/row`. Тайминги и тексты правятся в коде под слова Whisper. `node scripts/render_overlay.js preview <html> <src> <dir> t1 t2…` — кадры-превью поверх исходника; `node scripts/render_overlay.js build <html> <src> <out.mp4> 30 <сек> [crf]` — полная сборка, звук копируется как есть (`NODE_PATH=$(npm root -g)`) |
| `fonts/` | Montserrat Black/ExtraBold/SemiBold (+Italic), Unbounded Black, Bebas Neue — все с казахской кириллицей (OFL) |

Пути скриптов — относительно папки скилла. Нужен `ffmpeg` (с libass).

## Порядок работы

1. **Разобрать исходники:** `ffprobe` (размер, fps, длительность). Сохранять родной fps (24/25/30).
2. **Расшифровать речь** (Whisper или ElevenLabs `creative_transcribe_audio`) с таймкодами слов. Понять язык спикера: перевод в нижних субтитрах будет на **другом** языке (каз ↔ рус).
3. **Сценарий по шаблону** (см. reference.md §1): хук 0–3 c → объект/лого → 3–5 пунктов (одно ключевое слово на пункт) → оффер (цена/ставка/скидка) → CTA → аутро. Цель 35–50 c.
4. **Черновой монтаж:** вырезать паузы/оговорки (jump-cut, при нужде панч 105–115%), склейки по концу фразы, B-roll на каждом пункте (фасад, дрон, двор, интерьер, рендер). Первый кадр — лицо или цифра, без чёрного.
5. **Цвет:** `scripts/grade.sh` — `warm` для стройки/интерьеров/пасмурно, `clean` для светлого офиса и окон, `pop` для улицы/лета/событий. Один пресет на весь ролик.
   - **Если клиент просит оригинальный цвет — пропустить grade полностью**, только кроп/наезд.
   - **iPhone HDR (HLG, bt2020, 10 bit):** не тонмаппить (hable темнит и желтит, прямой zscale HLG→bt709 выбивает света). Ближе всего к оригиналу — просто `format=yuv420p` и пометить выход bt709 (`-color_primaries bt709 -color_trc bt709 -colorspace bt709`). Сравнить кадр до/после.
6. **Титры:** скопировать `templates/subs.ass`, заменить события:
   - крупный слой — 1 ключевое слово/цифра на пункт (`Glow` слой 0 + `Head` слой 1 с одинаковыми `\pos`), держится через склейки;
   - акценты — `Accent` (жёлтый) или зелёный неон для цены (`\c&H4FFF7C&` + glow-дубль `\3c&H3BFF3B&\blur16`);
   - нижний слой `Sub` — полный перевод каждой фразы.
   Позиции: заголовок y≈1100–1200 (грудь) или 250–450 (над головой); перевод — низ, MarginV 330. Не залезать в нижние 15% и верхние 8%.
7. **Звук:** `scripts/mix.sh` (музыка без вокала, звучит с первого до последнего кадра) + SFX: whoosh на переходах/титрах, pop на карточках, «cash» на цене, shimmer на аутро.
8. **Аутро 2.5–3 c** (reference.md §6): сине-фиолетовый градиент #24206B→#3A35A0, световая звезда из 4 лучей → «BI» → «BI GROUP» + логотип партнёра. Если есть оригинальный файл аутро от клиента — использовать его.
9. **Экспорт:** `scripts/export.sh graded.mp4 final.mp4 subs.ass mix.wav`.
10. **Проверка:** кадры на 3–4 таймкодах (контакт-лист), `ebur128` ≈ −14 LUFS, пройти чек-лист из reference.md §9.

## Режим «оригинал»: цвет, голос и музыка не трогать

Если клиент просит сохранить оригинал — **не вызывать `grade.sh` и `mix.sh`**, добавлять только графику:
1. Тайминги слов из Whisper → копия `templates/motion-overlay*.html` (заголовки, инфографика). Сначала `render_overlay.js preview` на 15–20 таймкодах, смотреть контакт-лист, затем `build`.
2. Сборка (внутри `build`): видео с `format=yuv420p` (без цветокора), оверлей переводить в YUV матрицей bt709: `[1:v]scale=out_color_matrix=bt709:out_range=tv,format=yuva420p[o];[b][o]overlay`, звук `-map 0:a:0 -c:a copy` (бит-в-бит). Проверка: `ffmpeg -i src -map 0:a:0 -f md5 -` и то же по результату — хэши равны.
3. Не обрезать начало/конец и не менять длительность без просьбы.
4. **Нижний русский перевод по умолчанию не добавлять** (клиент просил убрать); субтитры = крупные ключевые слова на языке речи, поправленные вручную (Whisper путает казахские слова — не выводить его сырой текст на экран).
5. Видео на 90 МБ в git не коммитить (лимит GitHub 100 МБ): класть в `output/` и в `.gitignore`.
6. Инфографика только из того, что сказано в речи; выдуманные цифры не рисовать (линии и иконки без значений).

## Для сложной графики

Анимации, которые ASS не тянет (набор по буквам с растворением, неон-градиент внутри букв, карточка планировки с pop-up, падающие купюры, звезда в аутро), делать в **Remotion** (скилл `remotion:remotion-best-practices`) или HyperFrames, используя размеры, цвета и шрифты из reference.md, и накладывать поверх видео.

## Принципы стиля (кратко)

- Двуязычие: крупное ключевое слово + мелкий полный перевод снизу.
- Белый текст с мягким свечением, без плашек; акценты жёлтым / зелёным неоном.
- Montserrat Black для заголовков, Unbounded Black для неона, Montserrat SemiBold для перевода.
- Кожа тёплая и натуральная, чёрные приподняты, мягкие света.
- Прямые склейки, ритм по смыслу, музыка без пауз, −14 LUFS.
