# B-Avenue Montage — стиль монтажа

Справочник по стилю, снятый с 5 референсных роликов (недвижимость / ипотечные программы, Казахстан, BI Group).
Задача документа: по нему можно смонтировать новый ролик «в том же почерке»: структура, ритм, шрифты, субтитры, цвет, звук, финальная заставка, экспорт.

---

## 0. Что было проанализировано

|---|-------|------:|----:|------:|-----:|----------|----------|
| 1 | ЖК Arena Vista: обзор «5 прилагательных на букву К» (спикер в спецовке) | 59.2 c | 30 | 17 | ~3.3 c | −14.3 LUFS, LRA 4.4 | тёплый, приглушённый «кино» |
| 2 | Программа 30/70 + Отбасы банк (спикер в светлом костюме, лобби) | 36.1 c | 24 | 4 | ~7 c | −14.1 LUFS, LRA 2.4 | тёплый, янтарь/дерево |
| 3 | «600 квартир без оценочного показателя» (спикер у окна) | 37.0 c | 30 | 10 | ~3.4 c | −14.2 LUFS, LRA 5.9 | холодный, чистый, сине-бирюзовый |
| 4 | #SummerWithBIgroup — селфи-влог спикера | 40.2 c | 30 | 5 (+коллаж) | ~6.7 c | −14.3 LUFS, LRA 5.2 | насыщенное лето, синее небо |
| 5 | Korkem Ипотека (двое спикеров, улица/офис) | 49.7 c | 25 | 8 | ~5.5 c | −14.1 LUFS, LRA 3.8 | яркий, контрастный, «неон» |

Общее у всех:
- **Формат:** вертикаль 9:16 (исходники 720×1280, делать в 1080×1920), H.264 + AAC 44.1/48 kHz stereo.
- **Длина:** 36–60 c. Целевая — **35–50 c**.
- **Громкость:** ровно **−14 LUFS integrated**, пик ≈ −0.5…0 dBTP, узкий LRA (2–6 LU) — голос плотно скомпрессирован.
- **Музыка звучит без пауз** под голосом от первого до последнего кадра (тишины > 0.3 c нет ни в одном ролике).
- **Нет затемнения в начале:** ролик открывается сразу говорящим лицом / сильным кадром — хук с первого кадра.
- **Двуязычие:** спикер говорит на казахском (или русском) → крупные заголовки на одном языке, нижние субтитры — перевод на другом языке. Это фирменная деталь стиля.

## 1. Структура ролика (шаблон)

```
0.0–3 c   ХУК       Спикер в кадре + крупный заголовок-цифра/вопрос (600 квартир / ПО ПРОГРАММЕ 30/70 / KORKEM ИПОТЕКАСЫ ЖАЛҒАСУДА!)
3–6 c     КОНТЕКСТ  Логотип/название объекта: «Жилой комплекс Arena Vista», логотипы-партнёры (BI GROUP + ОТБАСЫ БАНК)
6–35 c    ТЕЛО      3–5 пунктов. Каждый пункт = 1 слово/цифра крупно + B-roll объекта (фасад, дрон, двор, интерьер, рендер)
                    Возврат к спикеру между пунктами.
35–45 c   ОФФЕР     Цена / ставка / скидка: самый яркий титр ролика (зелёное свечение «57.000.000», «до 25%», «8% ставка»)
                    + планировка в белой карточке со скруглением.
последние CTA       «Напишите в комментариях слово …» / хэштег / подписка → 
2–3 c     АУТРО     Брендовая заставка: тёмно-синий/фиолетовый градиент + световая «звезда-вспышка» → появление логотипа BI GROUP (+ партнёр).
```

Правила структуры:
- Пункты нумеруются или объединены одной идеей (например, «5 прилагательных на букву К»: КАЧЕСТВЕННЫЙ / КОМФОРТНЫЙ / КРАСИВЫЙ / КУЛЬТУРНЫЙ / КЛАССНЫЙ).
- Один пункт = один заголовок на экране; заголовок держится всё время, пока о нём говорят, и **переживает склейки** (B-roll меняется, заголовок остаётся на том же месте).
- Перечень фактов можно давать на отдельном **градиентном инфо-слайде** (ролик 2): пункты 1-2-3-4 появляются по очереди и накапливаются на экране.

## 2. Монтаж и ритм

- **Монтаж по смыслу фразы**, а не по биту: склейка на конце фразы/слова-ключа. Средний план 3–7 c, в динамичных кусках 1–1.5 c (серия B-roll из 3–5 кадров подряд).
- **Переходы:** почти всегда прямая склейка. Допустимые акценты:
  - короткий **белый/световой флэш** 2–4 кадра на смене блока;
  - **whip/zoom-переход** (быстрый смаз) при прыжке спикер → B-roll;
  - **jump-cut** внутри одного плана спикера (вырезаны паузы и оговорки), иногда с лёгким **панчем 105–115%** для маскировки.
- **Виртуальная камера:** медленный push-in 100→106% на говорящих планах, на B-roll — лёгкий дрейф/параллакс; дрон и рендеры всегда в движении.
- **B-roll набор:** фасады снизу вверх, дрон сверху (top-down), двор/детская площадка/воркаут, пустые квартиры с окнами, рендер генплана с подписанными улицами (синяя линия-дорога + подпись «улица Толе Би»).
- **Графические вставки:** планировка в белой карточке (радиус ~24 px, тень), падающие купюры на цене, коллаж-«полароиды» с фото событий за спиной спикера (ролик 4), фигурные вырезы спикера поверх фона.
- **Селфи-формат** (ролик 4): широкоугольная камера на вытянутой руке, спикер идёт, смена локации на каждой фразе — каждая склейка = новое место, слово на экране меняется пословно.

Размеры (для 1080×1920):
- Главный заголовок: **80–110 px**, капс, трекинг 0…+1%, интерлиньяж 0.95–1.05.
- Гигантская цифра (600, 50%, 8%): **240–320 px**, к ней подпись 70–90 px.
- Неон-заголовок: **110–140 px**, 2–4 строки, занимает всю ширину с полями 60 px.
- Нижние субтитры: **34–40 px** (в исходниках мелкие), 1–2 строки, по центру.

Позиции (безопасные зоны Reels/TikTok):
- Главный заголовок — **центр по горизонтали**, по вертикали: либо на уровне груди спикера (~58–62% высоты), либо в верхней трети (12–25%) над головой.
- Нижние субтитры — **~80–83% высоты** (низ кадра, выше интерфейса соцсети). Отступы по бокам ≥ 90 px.
- Логотипы-партнёры — верх, ~10–25% высоты, по центру.

## 4. Субтитры

Два слоя одновременно:

### 4.1 Верхний слой — «ключевое слово» (крупно)
- Не дословная расшифровка, а **1 ключевое слово или короткая фраза/цифра** из того, что говорит спикер.
- Белый текст + **мягкое свечение/тень** (glow: blur 20–30 px, белый 35–50% непрозрачности) — текст будто «светится», читается на любом фоне.
- Акцент-слова — **жёлтым** (#FFE600) или **зелёным неоном** (#7CFF4F) с цветным свечением.
- Пословный вариант (ролик 4): по одному-два слова, меняются на каждом слове, ключевые слова жёлтые курсивные (ҚАЛАЙ ӨТТІ?, МҮМКІН, НЕМЕСЕ, ӘЛДЕ).
- Появление: **набор по буквам/слогам с растворением** (typewriter + fade, ~25–40 мс на букву) — ролик 2; или **scale-in 85→100% + fade** за 6–8 кадров; исчезновение — fade 4–6 кадров.

### 4.2 Нижний слой — перевод
- Полная фраза на **втором языке** (казахский ↔ русский).
- Белый, Medium/SemiBold, **без плашки**, лёгкая тень (0 2 6 rgba(0,0,0,.45)).
- Иногда курсив (ролик 4) с **выделением хэштегов/брендов жёлтым**.
- Строка меняется по фразам (не пословно), без анимации или короткий fade.

## 5. Цветокоррекция

Измерено (signalstats, средние по ролику, 8-bit):

| Ролик | Яркость Y | Тени (YLOW) | Света (YHIGH) | Насыщенность | Вывод |
|-------|----:|----:|----:|----:|------|
| 1 | 116 | 38 | 187 | 11.6 | приглушённый, десатурированный, «плёночный», тёплые тени, оранжевый костюм — единственное яркое пятно |
| 2 | 107 | 55 | 145 | 23.3 | мягкий контраст, приподнятые тени, тёплый янтарь (дерево, свет), кремовые светлые тона |
| 3 | 127 | 60 | 191 | 18.3 | светлый, воздушный, холодный бирюзово-синий фон + натуральная кожа |
| 4 | 113 | 29 | 198 | 15.0 | высокий контраст, синее небо, «солнечный» |
| 5 | 115 | 39 | 180 | 22.9 | сочный, насыщенный зелёный/синий, коммерческий |

Общий почерк:
- **Кожа всегда естественная и тёплая**, не перешарпленная.
- **Слегка приподнятые чёрные** (матовый «милк»-эффект), никакого «жирного» чёрного.
- **Мягкие света** (rolloff), окна не выбиты в белое полностью.
- Фон — либо тёплый янтарь (интерьеры), либо холодный teal/blue (улица, стекло) → классический **teal & orange**, но сдержанно.
- Лёгкое зерно и мягкая виньетка на «кино»-роликах (1, 2).

### Пресеты ffmpeg

**A. «Cinema Warm» (ролики 1–2: стройка, интерьер, хмурая погода)**

```

**B. «Clean Bright» (ролик 3: офис, окна, премиум)**
```

colorbalance=bs=0.04:gs=0.01:rh=0.02:bh=0.03

**C. «Summer Pop» (ролики 4–5: улица, небо, событие)**

## 6. Графика и анимации

- **Глоу-текст:** основной белый слой + размытый дубль под ним (blur 20–30, opacity 40–60%). Для неона (ролик 5) — градиент внутри букв (розовый #FF6BF0 → голубой #6FE8FF, голубой → лаймовый #9CFF57) + цветное свечение.
- **Цифры-офферы:** самый крупный элемент, зелёный неон (#7CFF4F, свечение #3BFF3B) или белый с металлическим градиентом (белый → светло-серый сверху вниз, ролик 3).
- **Партнёрские лого:** белые монохромные, по центру, «BI GROUP» сверху, партнёр (ОТБАСЫ БАНК / FREEDOM) под ним.
- **Карточка планировки:** белый прямоугольник, скругление ~24 px, тень, внизу кадра по центру, появляется pop-up (scale 80→105→100%, 10 кадров).
- **Рендер-карта:** голубая линия-дорога + наклонная подпись вдоль неё, название ЖК над объектом.
- **Инфо-слайд (ролик 2):** фон — градиент **#1B1F7A → #2C2BA8 → #5B3FB0** (сине-фиолетовый) с крупными полупрозрачными скруглёнными «капсулами»-контурами; пункты списка белым капсом с glow, появляются по одному.
- **Ярлык/инструкция (ролик 1):** синяя скруглённая плашка #2E3BFF с белым текстом — «Опиши проект 5 прилагательными на букву "К"».
- **Падающие купюры** на кадре с ценой.

### Аутро BI Group (2.5–3 c) — одинаковое в роликах 3 и 5
1. Фон: тёмный сине-фиолетовый градиент (#24206B → #3A35A0), в углах еле заметный казахский орнамент (5–8% opacity).
2. 0–0.6 c: из центра — **световая «звезда»** (4 луча, белые с фиолетовым краем) с бликом и искрами, лучи вращаются/вытягиваются.
3. 0.6–1.2 c: звезда сжимается в иконку **«BI»** (fade + scale).
4. 1.2–1.8 c: справа выезжает «GROUP», снизу появляется партнёр (зелёный логотип FREEDOM / ОТБАСЫ БАНК).
5. Держать 1 c, звук — светлый «вжух + звон» (whoosh + shimmer).

## 7. Звук

- **Голос:** шумодав, EQ (HPF 80 Hz, +2 dB 3–5 kHz для разборчивости), компрессия 3:1–4:1, лимитер. Голос всегда на первом плане.
- **Музыка:** корпоративный/вдохновляющий поп-эмбиент или лёгкий хаус, без вокала, звучит **непрерывно** с первого кадра, под голосом на −18…−22 dB относительно него (ducking/sidechain).
- **SFX:** whoosh на переходах и появлении титров, «pop» на карточках, «cash»/монеты на цене, shimmer на аутро.
- **Мастер:** **−14 LUFS integrated, −1 dBTP**.

```
ffmpeg -i voice.wav -i music.mp3 -filter_complex \
"[0:a]highpass=f=80,afftdn=nf=-25,equalizer=f=4000:t=q:w=1:g=2,acompressor=threshold=-18dB:ratio=3.5:attack=5:release=120[v];\
 [1:a]volume=0.25[m];[m][v]sidechaincompress=threshold=0.05:ratio=8:attack=20:release=300[md];\
 [v][md]amix=inputs=2:normalize=0,loudnorm=I=-14:TP=-1:LRA=6[a]" -map "[a]" mix.wav
```

## 8. Экспорт

```
ffmpeg -i edit.mov -vf "scale=1080:1920:flags=lanczos,format=yuv420p" \
  -c:v libx264 -preset slow -crf 18 -profile:v high -r 30 -movflags +faststart \
  -c:a aac -b:a 192k -ar 48000 out_1080x1920.mp4
```
- 1080×1920, 30 fps (или 25/24, если исходник так снят — не конвертировать частоту без нужды), BT.709, yuv420p.
