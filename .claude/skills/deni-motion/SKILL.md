# deni_motion

Скилл Дени для моушн-графики. Три закона ниже обязательны всегда; модули из `references/` подключай только когда задача их требует. Явные слова пользователя (формат, длительность, звук, стиль, язык) важнее любых значений по умолчанию. Короткой идеи достаточно — творческие решения принимай сам, техническую анкету не устраивай.

**Движок:** HyperFrames (HTML → видео). Перед первой сборкой прочитай скилл `hyperframes` и соблюдай его контракт рендера; готовые блоки сначала ищи в `hyperframes-registry`. Свои HTML/CSS/SVG/Canvas — когда блока нет. Лишние зависимости не ставь.

---

## Закон 1. Режиссура раньше кода

1. Вытащи из брифа: о чём ролик одной фразой, для кого, обязательный текст, формат, длительность, язык, звук, исходники (клипы Seedance, фото, голоса).
2. Придумай **одну сквозную нить** — что меняется от начала к концу (материал, предмет, слово, пространство). Сцены связаны причиной, а не просто идут подряд.
3. Для каждой сцены — 3 разных варианта постановки одной строкой (разное действие/пространство/переход, не просто другой цвет). Выбери один, причину — одной фразой.
4. Заполни карточки сцен по шаблону из [раскадровки](references/storyboard.md) и покажи пользователю коротко (таблица). Ждать одобрения — только если он просил.
5. Самый рискованный момент (сложный переход, буквы с кириллицей/казахскими знаками, 3D) сначала проверь коротким тестом на 2–3 секунды.

## Закон 2. Живое движение и звук по умолчанию

- Камера и слои движутся осмысленно: передний / средний / задний план с разной скоростью, разгон и торможение, без линейного зума плоской картинки. Финальный читаемый кадр может стоять.
- Текст — актёр, а не подпись: собирается, ломается, взаимодействует с объектом. Но сначала спроектируй финальную читаемую раскладку, потом его движение.
- Объекты имеют вес, инерцию, тень, контакт, отскок.
- Motion blur по скорости, глубина резкости на близких планах, плёночное зерно — когда это поддерживает стиль.
- **Звук по умолчанию есть:** музыка + звуковой дизайн, ключевые действия попадают в акценты. Генерация через коннектор ElevenLabs (сначала назови стоимость в кредитах). Если пользователь сказал «без звука» или «музыку добавлю сам» — делай как сказано и честно пиши, что ролик немой / только SFX.
- Детали: [движение](references/motion-craft.md), [звук](references/sound.md), [стили Дени](references/styles.md), [казахская типографика](references/kazakh-type.md).

## Закон 3. Первая сборка — черновик. Смотри, чини, сдавай

1. Отрендерь черновик, затем **сам посмотри**: контактный лист кадров каждой сцены и всех стыков, первые и последние 0,5 с, читаемость каждой надписи (успевает прочитаться?), обрезка у краёв, артефакты.
2. Прослушай/проверь звук: есть ли он, не клиппует ли, совпадают ли акценты с действиями.
3. Исправь причины дефектов, перепроверь изменённое и ролик целиком. Обычно нужно 1–2 круга.
4. Сдавай только проверенный файл. Чего проверить не смог — назови прямо.

**Экспорт по умолчанию:** MP4, H.264, yuv420p, AAC 48 кГц, 30 fps (60 — по запросу или для очень быстрого движения). Размер: 1920×1080 для YouTube/кино; 1080×1920 для Reels/Shorts/TikTok. Исходники HyperFrames сохраняй рядом. Команды проверки — в [проверке и экспорте](references/review-export.md).

## Модули по задаче

- Графика и титры поверх клипов Seedance / своего видео, финальные исторические карточки: [поверх видео](references/over-footage.md) — **факты только из найденных реальных статей, с источниками**.
- Анимация интерфейса, приложения, продукта: [UI-моушн](references/ui-motion.md).
- Сделать «как в этом ролике»: разбери референс по [референсам](references/references.md), перенеси приёмы, а не копируй чужой ролик целиком.

## Чего не делать

- Не копировать чужие ролики, персонажей, логотипы, фирменные стили один в один.
- Не выдумывать факты, цифры, свойства продукта. Для исторических тем — только проверенное, с источниками.
- Не тратить кредиты (ElevenLabs, Higgsfield) без названной стоимости; видео в Seedance не генерировать без разрешения.
- Не называть HTML-превью готовым видео и не заявлять проверку, которой не было.
