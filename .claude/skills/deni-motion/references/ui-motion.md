# UI-моушн

- Интерфейс собрать в HTML как настоящий (сетка, реальные состояния), а не картинкой.
- Курсор: движется по дуге с ease-in-out, перед кликом замедляется, клик = лёгкое сжатие кнопки 0,96 + звук.
- Показывать состояния: пусто → ввод → загрузка → результат. Не выдумывать функций продукта.
- Камера: наезд на зону действия, наклон 3D-экрана 5–15°, параллакс карточек.
- Переходы между экранами — через общий элемент (карточка разворачивается в следующий экран).
