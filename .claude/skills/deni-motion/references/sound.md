# Звук

- По умолчанию: музыкальная подложка + SFX (свуши на переходах, удары на акцентах, тихие «тики» на буквах, атмосфера).
- Генерация — через коннектор ElevenLabs: музыка (`music` скилл для понимания модели), SFX (`sound-effects`), голос (`text-to-speech`, модель eleven_v4). Всегда сначала назвать стоимость в кредитах.
- Казахский голос: проверенные голоса — Aruzhan kaz (жен.), Adi, Ерсұлтан (муж.). Детский казахский голоса нет — ближайший Tuana Öztürk.
- Синхронизация: после получения реальной дорожки найти пики (`ffmpeg -i music.mp3 -af "astats=metadata=1:reset=1" ...` или на слух), записать таймкоды и привязать к ним ключевые действия с точностью до кадра (кадр = время × fps). Не каждый бит — смена кадра, только смысловые акценты.
- Микс: голос −16…−14 LUFS итог, музыка под голосом на 12–18 дБ тише, пики не выше −1 dBTP.
- Если пользователь добавит музыку сам — делать только SFX/голос и оставить чистую дорожку.
