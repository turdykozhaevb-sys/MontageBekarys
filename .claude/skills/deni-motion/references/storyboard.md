# Раскадровка deni_motion

## Порядок
1. Одна фраза: «Ролик про ___, зритель должен почувствовать/понять ___».
2. Сквозная нить: что меняется от первого кадра к последнему.
3. Тайминг: на короткую фразу — минимум 1,2 с чтения, на 6–10 слов — 2,5–3 с. Ролик 15 с ≈ 4–6 сцен; 30 с ≈ 6–9; 60 с ≈ 10–14.
4. Для каждой сцены 3 варианта → выбор → карточка.
5. Проверка ритма: нет ли двух одинаковых переходов подряд, нет ли сцены, где «ничего не происходит».

## Карточка сцены

| Поле | Что записать |
|---|---|
| Время | 0:00–0:03 |
| Смысл | что зритель должен понять здесь |
| Действие | что было → что запускает изменение → что стало |
| Планы | передний / средний / задний, свет, фактура |
| Текст | точная фраза + как движется + сколько держится |
| Камера | путь, скорость, крупность, фокус/blur |
| Вход / выход | чем связана с предыдущей и следующей сценой (предмет, цвет, движение, звук) |
| Звук | музыкальный акцент + SFX + что с ним совпадает |
| Риск | что может не получиться и как проверю |

## Типовые переходы (не повторять один и тот же подряд)
Перелёт камеры сквозь объект · предмет становится следующей сценой (match cut по форме) · маска по букве/форме · свип по направлению движения · смена масштаба (макро → общий) · удар/вспышка на акцент · разрыв бумаги/плёнки · затемнение на тишине (для драмы).
