# Казахская типографика

- Обязательные глифы: Ә ә Ғ ғ Қ қ Ң ң Ө ө Ұ ұ Ү ү Һ һ І і. Перед сборкой отрендерить тестовую строку: «Әке, ғашық, қазақ, теңге, өмір, ұлт, үй, һәм, іні».
- Проверенные шрифты с казахской кириллицей (Google Fonts): Montserrat, Inter, Roboto, Noto Sans/Serif, PT Sans/Serif, Rubik, Manrope, Unbounded, Oswald, Playfair Display, Lora, IBM Plex Sans/Serif. Перед использованием всё равно проверить тестовую строку.
- Казахские слова длиннее русских — закладывать запас ширины 15–20 %, переносы ставить вручную.
- Кавычки «ёлочки», тире «—» с пробелами.
- Латиница (2031+) — только по просьбе.
