# Ремесло движения

## Тайминг и кривые
- Входы: ease-out (быстро начал, мягко сел), 0,4–0,8 с. Уходы: ease-in, быстрее входа.
- Акценты: лёгкий перелёт 3–8 % и возврат (back/elastic слабые). Тяжёлые предметы — без пружины, с осадкой.
- Наложение: элементы стартуют со сдвигом 40–120 мс (не все сразу).
- Не держать «мёртвый» кадр дольше 1,5 с без микродвижения, кроме финала и драматических пауз.

## Глубина
- Минимум 3 слоя с разной скоростью параллакса (фон 0,2×, середина 0,6×, передний 1×+).
- Перспектива CSS 3D: `perspective` 1200–2000px, наклоны 3–12°. Камера = общий родитель-контейнер, анимируется он.
- DOF: размытие фона 4–12px на близких планах, передний план иногда тоже в размытии.
- Motion blur: в HyperFrames — несколько полупрозрачных копий по траектории или CSS `filter: blur()` по оси на пике скорости; убирать на остановке.

## Типографика
- Сначала финальная раскладка (иерархия, кегли, переносы), потом анимация.
- Приёмы: сборка по буквам со сдвигом, раскрытие маской, растяжение ширины (variable font `wdth`), буквы как физические объекты (падают, стыкуются), слово заменяет предмет.
- Минимальный кегль: 1080p — 42 px для основного текста, 1080×1920 — 56 px. Безопасные поля: 5 % по краям, в вертикальном — сверху 12 %, снизу 18 % (интерфейс соцсетей).

## Свет и фактура
- Мягкий градиентный свет, виньетка 10–25 %, зерно 2–4 % — убирает «пластиковость».
- Тень всегда в одном направлении во всей сцене.
