# CapCut

Вариант A (надёжный): CapCut → New project → импорт `out/dent-a-protez_no_subs.mp4` + `public/voice.mp3`,
затем Text → Captions → Import subtitle → `Dent-A_Protez.srt`. Субтитры редактируются как обычный текст.

Вариант B (готовый проект): скопируйте папку `Dent-A_Protez` в папку черновиков CapCut
(Windows: `%LocalAppData%\CapCut\User Data\Projects\com.lveditor.draft\`), перезапустите CapCut.
Дорожки: видео (8 сцен отдельными клипами), озвучка, 37 субтитров. Если CapCut не откроет черновик
(формат между версиями меняется) — используйте вариант A.
Моушн-графика (карточки, монета, подарок) вшита в видео-дорожку; субтитры — отдельный слой.
